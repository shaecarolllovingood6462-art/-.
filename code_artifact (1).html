🎮 게임 방법 (꼬맨틀 원리)

  • 정답 단어의 글자 수가 아닌, 문맥적·의미적 유사도를 추론합니다.
  • 유사도는 0점에서 100점까지 계산되며, 점수가 높을수록 정답과 가까운 의미입니다.
  • 유사도가 매우 높은 상위 단어들은 순위(Top 1~1000위)가 표시됩니다.

📚 핵심 문법 개념: 단어 형성의 원리

단일어

하나의 어근(실질 형태소)만으로 이루어진 단어

예시: 나무, 하늘, 바다, 구름, 사람, 길, 집

합성어

둘 이상의 어근이 결합하여 이루어진 단어 (어근 + 어근)

예시: 돌다리(돌+다리), 밤낮(밤+낮), 눈물(눈+물), 책가방(책+가방)

파생어

어근에 접사(접두사 또는 접미사)가 결합하여 이루어진 단어

예시: 풋사과(풋-[접두사] + 사과), 멋쟁이(멋 + -쟁이[접미사]), 먹보(먹- + -보)

💡 수업 활동 팁
